# Configure a Wireless Router and Client

This lab was completed using Cisco Packet Tracer as part of my Networking Essentials coursework at Valencia College.

## Objective

The objective of this lab was to configure a wireless router and connect a client to the wireless network.

## What I Practiced

* Configuring a wireless router
* Setting up a wireless network
* Configuring a wireless client
* IP addressing
* DHCP
* Testing network connectivity
