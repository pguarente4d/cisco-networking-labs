# Cisco Networking Labs

This repository contains networking labs I completed using Cisco Packet Tracer as part of my Networking Essentials coursework at Valencia College.

## Labs

### 1. Configure a Wireless Router and Client

This lab focuses on configuring a wireless router, connecting a wireless client, and testing network connectivity.

[View Lab File](./Configure%20a%20Wireless%20Router%20and%20Client.pka)

### 2. Configure SSH

This lab focuses on configuring Secure Shell (SSH) for remote access to a network device.

[View Lab File](./Configure%20SSH.pka)

### 3. Connect a Network Based on a Network Diagram

This lab focuses on connecting network devices based on a provided network diagram and verifying network connectivity.

[View Lab File](./Connect%20a%20Network%20Based%20on%20a%20Network%20Diagram.pka)

### 4. Observe Traffic Flow in a Routed Network

This lab focuses on observing how network traffic moves through a routed network and understanding how routers forward packets between networks.

[View Lab File](./Observe%20Traffic%20Flow%20in%20a%20Routed%20Network.pka)
